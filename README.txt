Eircode Address Finder

How to install:
1. Open Chrome.
2. Go to chrome://extensions.
3. Turn on Developer mode.
4. Click Load unpacked.
5. Select this folder.

How to use:
1. Highlight an Eircode on any webpage.
2. Right-click and choose Find address for selected Eircode.
3. Or press Alt + Shift + E.
4. A result card appears on the page with the full address, address details, matching options, copy buttons, and a Google Maps button.

You can also click the extension icon and enter an Eircode manually.

API:
This extension uses the Autoaddress Find Address endpoint and the API key supplied by the user.
